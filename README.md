# Altar

Altar is a free, open-source guitar amplifier. 

It is designed to be a feature-complete competitor to existing closed models. 

No license, no subscription, no bullshit.

## Features

- Standalone & Plugin Formats (AU, VST3)
- Modular DSP:
  * Multiple Amp Models
  * Cab IRs
  * Multiple OD Pedals
  * Delay with Reverse & Glitch Modes
  * Reverb, Chorus, Ringmod
- NAM & NAM A2 support
- Cab Designer
- Realtime Pitch Shifting
- Pre & Postprocess Chains
- Tuner, Click, Memo Recorder
- Mono & Stereo Support
- Preset Management
- Module and Patch randomization
- ~8x Oversampling
